# Campagnes en one-shots

Deze fase sluit de bestaande campagne- en one-shotoverzichten en detailroutes aan op de PHP API. Beide gebruiken `campaigns.type`; er is geen tweede one-shottabel of backendarchitectuur.

Status: frontendkoppeling, API-detail, create/edit, archiveren en optimistic locking zijn geïmplementeerd. Restore is aanwezig in de UI maar de runtimecheck faalde nog; productiegeschiktheid wordt niet geclaimd.
